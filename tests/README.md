# 合成文本对照记录

这是一次已完成的小样本测试记录，不是运行器，也不是可重复调用模型的自动测试套件。原始运行日志与本机配置不公开。

## 方法

- 4个独立设计的新合成案例，每题一个首问和一个固定后续消息。
- 普通助手条件不注入 ah-think；Skill 条件注入完整 SKILL.md、choice.md、reality.md。其他共同设置一致。
- 每条件每题一次两轮文本回放，共16次生成；第二轮带入各自首答，不是原生连续会话。
- 题目和判据在生成前冻结，生成者不见判据。
- 两位独立 AI 评审只读取匿名回答与判据。逐条评分后才揭示条件，不按字数直接判优，允许平局。

## 结果

两位评审的必检评分均为：普通助手12/12、Skill12/12。可选项均为：普通助手3/4、Skill2/4。帮助自主思考维度仅C3有一位评审选择Skill，另一位判平局；其他案例及阅读/操作负担维度均为平局。不能据此证明总体优越性，也不因可选项分差断言总体劣势。

## 文件

- `cases.json`：首问和固定后续。
- `rubric.json`：判据、适用轮次与两个比较维度。
- `answers.json`：两条件的完整匿名回答。
- `judge-one.json`、`judge-two.json`：独立逐项评审及理由。
- `conditions.json`：每题A/B对应条件，便于核对；不在生成和盲评时提供。

## 环境与限制

本机请求配置为gpt-6-sol / low，服务端实际模型未独立核实。自动Skill发现、相关记忆和hooks等功能关闭，但两组共有通用全局协作指令，不能称为纯净基础模型。未观察到生成过程中的工具调用，不等于所有工具不可见。

CLI报告两条共同的启动诊断：实验功能chronicle启用，以及缺少本地模型规格信息、采用回退规格。运行器起初将诊断当成异常事件而暂停；独立审计只检查事件类型，确认调用正常完成后，保留全部8个首答，再完成原计划8个第二轮回答。没有重抽首答或改题。环境诊断使本轮不能代表该模型的标准运行表现。

4题、单次采样、AI评审、完整文本注入的结果，不能推出真人体验、自主能力改善、后续迁移、原生路由表现或跨环境稳定性。
