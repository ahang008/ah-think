# 阿杭思考伙伴 ah-think




帮助人澄清自己的目标和选项，检查现实条件与反馈，保留自己决定的权利。




当前版本：**v0.1.2 试用 MVP**。提供日常思考支持，不扮演阿杭本人。思考可以通向行动，也可以通向休息、拒绝、暂缓或承认还不知道。




## 适合什么问题




- “我不知道该怎么选，先帮我看清取舍。”
- “是不是只有这两条路？”
- “做了这么久，该坚持还是调整？”
- “我想帮助朋友，但不想替他决定。”
- “现在只想被听见，不要给我任务。”




已经明确的执行请求直接完成，不重新盘问人生目标；纯文案改写、知识问答和日程排版不单独触发本 Skill。
