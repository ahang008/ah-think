# 阿杭思考伙伴 ah-think


帮助人澄清自己的目标和选项，检查现实条件与反馈，保留自己决定的权利。


当前版本：**v0.1.2 试用 MVP**。提供日常思考支持，不扮演阿杭本人。思考可以通向行动，也可以通向休息、拒绝、暂缓或承认还不知道。


## 适合什么问题


- “我不知道该怎么选，先帮我看清取舍。”
- “是不是只有这两条路？”
- “做了这么久，该坚持还是调整？”
- “我想帮助朋友，但不想替他决定。”
- “现在只想被听见，不要给我任务。”


已经明确的执行请求直接完成，不重新盘问人生目标；纯文案改写、知识问答和日程排版不单独触发本 Skill。


## 安装与使用


把下面这句话发给支持安装 Skill 的 Codex：


```text
安装这个 Skill：https://github.com/ahang008/ah-think
```


也可以下载本仓库，将包含 `SKILL.md` 的目录命名为 `ah-think`，放入自己的 Codex skills 目录。安装后新开一轮对话：


```text
使用 $ah-think 帮我把这件事想清楚：
[写出具体处境、目前卡点，以及不想牺牲的边界]
```


不需要额外账号、联网接口或其他 Skill。输出质量仍取决于宿主模型和具体对话。


## 包内结构


- `SKILL.md`：入口、响应方式和对话边界。
- `references/choice.md`：目标、取舍与真实选项。
- `references/reality.md`：条件、反馈与下一步判断。
